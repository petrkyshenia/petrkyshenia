# OPUS 5.5 — промо-ролик 10,3 с

Готовый файл: [`renders/opus-5-5.mp4`](renders/opus-5-5.mp4) — 1920×1080, 30 fps, 309 кадров (10,3 с), H.264 + AAC 48 кГц.

Всё сделано кодом: [Remotion](https://www.remotion.dev) (React) для кадров, three.js для 3D,
собственный синтезатор на Node (без зависимостей) для музыки.

## Главы

| Время | Кадры | Что происходит |
|---|---|---|
| 0–1,3 с | 0–38 | Интро: циферблат-таймер, на 0,34 с удар — цифры врезаются, таймер улетает в HUD |
| 1,3–3,3 с | 39–98 | «ГРАФИКА»: золотой 3D-узел (torus knot 3,5) рисует сам себя по синему чертежу |
| 3,3–5,3 с | 99–158 | Объёмный хромированный «OPUS» на градиенте; «5.5» врезается ровно на 4,9 с (кадр 147): осколки, ударные волны, тряска камеры |
| 5,3–7,3 с | 159–218 | Печатается промпт, слова осыпаются и по спирали схлопываются в золотую 3D-«1» на 6,5 с |
| 7,3–9,3 с | 219–278 | «ЗВУК»: 16 3D-пэдов светятся под барабаны дропа (тот же паттерн, что играет синтезатор), анализатор спектра, фильтр открыт |
| 9,3–10,3 с | 279–308 | Финальный 3D-логотип «OPUS 5.5», сборка на ударе 9,34 с, таймер доходит до 10,30 |

Палитра: фон `#07070A`, золото `#FFC23D`, розовый `#FF3D7F`, бирюзовый `#25E2FF`.
Шрифты: Unbounded 900 — заголовки и 3D-текст, JetBrains Mono — подписи (оба SIL OFL, лежат в `public/fonts`).

## Звук

`scripts/synth.mjs` → `public/music.wav`. 120 BPM, ля минор (Am – F – G – E → дроп Am – F – G → Am).
До 7,3 с всё играет через закрытый ФНЧ 24 дБ/окт (~440 Гц, «за стеной»), на 7,24–7,36 с фильтр
раскрывается до 20 кГц. Удары (саб-бум + шум, на взрыве — треск, на «1» — колокол) стоят на
0,34 / 4,88 / 6,5 / 9,34 с. Лимитер с запасом под AAC, итог около −13,7 LUFS.

`src/audio/score.json` — общая партитура: синтезатор берёт из неё удары, аккорды и барабанный
паттерн дропа, а 3D-пэды — тот же паттерн, поэтому свечение совпадает с ударами покадрово.

## Сборка

```bash
npm install
npm run music                    # пересобрать public/music.wav
npm run studio                   # превью в Remotion Studio
npm run render                   # music + рендер в renders/opus-5-5.mp4
npm run check                    # QA рендера
```

Если Remotion не может скачать свой Chrome Headless Shell, укажите локальный браузер:
`REMOTION_BROWSER=/path/to/headless_shell npm run render`. WebGL рендерится программно (SwiftShader),
GPU не нужен.

## Проверка (`scripts/check.mjs`)

- формат: 1920×1080, 30 fps, 309 кадров, есть аудиодорожка;
- пересвет: доля «выбитых» в белое пикселей (все каналы ≥ 250) в каждом кадре < 0,2 %, средняя яркость
  кадра < 45 %, скачок яркости между соседними кадрами < 12 %;
- звук: громкость −16…−11 LUFS, true peak ≤ −1 dBTP, атака каждого удара в пределах ±20 мс от
  партитуры, доля энергии выше 2 кГц после 7,3 с в разы выше, чем до (фильтр реально закрыт/открыт);
- читаемость: кадры уменьшаются до 1000 px по ширине для просмотра. Самый мелкий текст в ролике — 32 px,
  в карточке 1000 px это ≈ 17 px.

# Зерна · тизер фази 0 «Дізнайтеся першими»

Reels 1080×1920, 30 fps, 15 с. Повторює структуру трендового ролика «Are you ready? Something big is coming. Stay tuned»
з тією самою музикою, але українською, у фірмовому стилі Zerna Development.

Готовий файл: [`renders/zerna-teaser-A.mp4`](../renders/zerna-teaser-A.mp4) — з вшитою музикою (публікуємо саме його).

## Текст (варіант A, тон «шепотом», на «ви»)

`А / ВИ / ГОТОВІ?` (глітч) → `НОВИЙ / ПРОЄКТ / У / КАРПАТАХ` → картинка + «ВАРТУЄ УВАГИ» →
«ВСЬОГО 130 КМ ВІД ЛЬВОВА» → «НА ВЕРШИНІ ГОРИ» → «ЛИШЕ 24 БУДИНКИ» → логотип, «ДІЗНАЙТЕСЯ ПЕРШИМИ»,
«посилання в шапці профілю». Головна інтрига стратегії плюс три якорі фази 0 (рядок «Чим говоримо»).
Увесь текст у `src/zerna/theme.ts` (`TEXT`).

## Стиль

Брендбук Zerna Development: кольори Deep Forest Green `#08281D`, Soft Ivory `#FAF6F0`, Warm Sand `#C0AF94`,
Sunny Yellow `#FDD64C`; заголовки Murs Gothic Wide Dark, текст e-Ukraine. У глітчі на 0,9 с додатково миготять
Playfair Display, Oswald, Caveat, Lobster, Comfortaa (усі з кирилицею, SIL OFL). Логотип вирізано з брендбука
(`public/zerna/logo-vertical-ivory-sand.png`, вертикальний, Ivory + Sand для зеленого фону).

## Картинка і світло

Нічний рендер генплану «Зерна» згори (`public/zerna/genplan-night.jpg`, 2000×1121) у темряві, з повільною
панорамою зліва направо; тепла смуга світла (спільний компонент `src/zerna/Sweep.tsx`, той самий, що в тизері 2)
на кожен удар переходить до того, про що каже текст: ліс і перші будинки → дорога → верх плану → група будинків.
Рендер нічний, тому світло підсилене (`gain: 1.9`). Текст стоїть у верхній третині кадру.

Щоб замінити картинку: покласти файл у `public/zerna/`, у `src/Root.tsx` змінити `picture.src`, `size`, `cx` (яка
точка картинки в центрі кадру на початку і в кінці панорами), `gain` і `light` — ключові кадри `[кадр, позиція
смуги %]` уздовж діагоналі 118° (0 — лівий верхній кут, 100 — правий нижній). Далі
`npm run zerna:render && npm run zerna:check`.

## Збірка

```bash
npm install
npm run studio          # превʼю: композиція ZernaA
npm run zerna:music     # пересобрати public/zerna/music-tail.wav
npm run zerna:render    # renders/zerna-teaser-A.mp4
npm run zerna:check     # QA проти референсу
npm run zerna:stills -- out ZernaA 30 80 270 400   # окремі кадри
```

Якщо Remotion не може завантажити свій браузер: `REMOTION_BROWSER=/path/to/headless_shell` і `--browser-executable`.

## Звук

- `public/zerna/music.wav` — доріжка, витягнута з референсу (`zerna-teaser/reference/reference.mp4`) без змін.
  Трек обривається одразу після фінального удару (11,83–11,88 с).
- `public/zerna/music-tail.wav` (`scripts/zerna-tail.py`) — той самий трек, до 11,86 с біт-у-біт ідентичний оригіналу,
  далі відлуння фінального удару: повтори через долю (0,43 с при 140 BPM), кожен на ~4 дБ тихіший і глухіший,
  по черзі ліворуч/праворуч, плюс короткий шлейф реверберації. Затихає до 14,9 с, тож при повторі рілса старт
  знову з тиші, як в оригіналі. Ролик використовує саме цей файл.

## Перевірка (`scripts/zerna-check.mjs`)

- 1080×1920, 30 fps, 450 кадрів, H.264 yuv420p, BT.709 з обмеженим діапазоном (рендер з `--color-space=bt709`), є аудіо;
- усі 26 змін кадру до 7,47 с (слова й кожен кадр глітчу) стоять на тих самих кадрах, що в референсі;
- музика стартує синхронно з референсом (±5 мс), гучність −16…−12 LUFS, пік ≤ −0,5 dBFS;
- після фінального удару звучить відлуння (11,95–12,6 с гучніше −40 dBFS), а в точці повтору (14,9–15 с) тиша.

  (обмежити охоплення або вимкнути звук); як реклама в Meta такий ролик не пройде — для реклами потрібна інша музика.
- Увесь текст стоїть поза зонами інтерфейсу Reels (верхні ~12 % і нижні ~20 % кадру вільні від важливого).

  зелене затемнення, вертикальний логотип, «А ВИ ГОТОВІ?» жовтим, «НОВИЙ ПРОЄКТ У КАРПАТАХ», «Всього 130 км від Львова»).
  Усе важливе в межах безпечних зон 250 px і в центральній ділянці 3:4, яку показує сітка профілю.
  Перегенерувати: `npm run zerna:covers` (код у `src/zerna-cover/Cover.tsx`).

# Зерна · тизер фази 0 «Дізнайтеся першими»

Reels 1080×1920, 30 fps, 15 с. Повторює структуру трендового ролика «Are you ready? Something big is coming. Stay tuned»
з тією самою музикою, але українською, у фірмовому стилі Zerna Development.

Готові файли:

- [`renders/zerna-teaser-A.mp4`](../renders/zerna-teaser-A.mp4) — з музикою (для перегляду та сторіс);
- [`renders/zerna-teaser-A-silent.mp4`](../renders/zerna-teaser-A-silent.mp4) — без звуку, для публікації в Instagram
  з оригінальним звуком через «Використати аудіо» (монтаж стоїть на тому самому треку з 0:00, тож синхрон збережеться).

## Текст (варіант A, тон «шепотом», на «ви»)

`А / ВИ / ГОТОВІ?` (глітч) → `НОВИЙ / ПРОЄКТ / У / КАРПАТАХ` → картинка + «ВАРТУЄ УВАГИ» →
«ВСЬОГО 130 КМ ВІД ЛЬВОВА» → «НА ВЕРШИНІ ГОРИ» → «ЛИШЕ 24 БУДИНКИ» → логотип, «ДІЗНАЙТЕСЯ ПЕРШИМИ»,
«посилання в шапці профілю». Головна інтрига стратегії плюс три якорі фази 0 (рядок «Чим говоримо»).
Увесь текст у `src/zerna/theme.ts` (`TEXT`).

## Стиль

Брендбук Zerna Development: кольори Deep Forest Green `#08281D`, Soft Ivory `#FAF6F0`, Warm Sand `#C0AF94`,
Sunny Yellow `#FDD64C`; заголовки Murs Gothic Wide Dark, текст e-Ukraine. У глітчі на 0,9 с додатково миготять
Playfair Display, Oswald, Caveat, Lobster, Comfortaa (усі з кирилицею, SIL OFL). Логотип вирізано з брендбука
(`public/zerna/logo-vertical-ivory-sand.png`, вертикальний, Ivory + Sand для зеленого фону).

## Як замінити картинку

1. Покладіть файл у `public/zerna/` (бажано від 2000 px по короткій стороні).
2. У `src/Root.tsx` змініть `picture.src` і `focus` — центр (`x`, `y` у % кадру) і радіус (`r`, % ширини)
   тієї однієї деталі, що лишається різкою.
3. `npm run zerna:render && npm run zerna:check`.

Зараз стоїть стиснене фото з дрона (`picture-placeholder.jpg`, 1280 px); різка ділянка на повороті серпантину (x 60 %, y 37 %).

## Збірка

```bash
npm install
npm run studio          # превʼю: композиція ZernaA
npm run zerna:render    # renders/zerna-teaser-A.mp4 і -silent.mp4
npm run zerna:check     # QA проти референсу
npm run zerna:stills -- out ZernaA 30 80 270 400   # окремі кадри
```

Якщо Remotion не може завантажити свій браузер: `REMOTION_BROWSER=/path/to/headless_shell` і `--browser-executable`.

`public/zerna/music.wav` — доріжка, витягнута з референсу (`zerna-teaser/reference/reference.mp4`) без змін.

## Перевірка (`scripts/zerna-check.mjs`)

- 1080×1920, 30 fps, 450 кадрів, H.264 yuv420p, BT.709 з обмеженим діапазоном (рендер з `--color-space=bt709`), є аудіо;
- усі 26 змін кадру до 7,47 с (слова й кожен кадр глітчу) стоять на тих самих кадрах, що в референсі;
- музика стартує синхронно з референсом (±5 мс), гучність −16…−12 LUFS, пік ≤ −0,5 dBFS;
- версія без звуку не має аудіодоріжки і має ті самі зміни кадрів.

## Публікація

- Найкраще публікувати версію без звуку й додавати оригінальний звук в Instagram: так трек ліцензований,
  а ролик чіпляється до тренду. Як реклама в Meta трек з бібліотеки Instagram не пройде: для реклами потрібна інша музика.
- Увесь текст стоїть поза зонами інтерфейсу Reels (верхні ~12 % і нижні ~20 % кадру вільні від важливого).
- Обкладинка для сітки профілю: кадр із логотипом і закликом (13 с) або «ВАРТУЄ УВАГИ» над картинкою (8,4 с).

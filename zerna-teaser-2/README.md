# Зерна · тизер 2, фаза 0 «Дізнайтеся першими»

Reels 1080×1920, 30 fps, 15 с, музика вшита. Повторює структуру трендового ролика «ARE YOU READY? … Yes, Future»
(`zerna-teaser-2/reference/reference.mp4`, 720×1280, 150 BPM) у фірмовому стилі Zerna Development.

Готовий файл: [`renders/zerna-teaser-2.mp4`](../renders/zerna-teaser-2.mp4).

## Текст (тон «шепотом», на «ви»)

Постери «ВАРТО УВАГИ» → `А ВИ` / `ГОТОВІ?` (як у першому тизері, щоб пости читалися серією) → генплан у темряві →
логотип, «КЛУБНЕ МІСТЕЧКО · КАРПАТИ», «ДІЗНАЙТЕСЯ ПЕРШИМИ», «посилання в шапці профілю». Увесь текст у
`src/zerna2/theme.ts` (`TEXT2`).

## Ресурси (`public/zerna2/`)

- `wood-wall.jpg` — процедурна стіна з дощок (`scripts/zerna2-wood.py`), без сторонніх текстур;
- `paper.png`, `icon-green.png` — папір постерів і паросток із логотипа (`scripts/zerna2-paper.py`);
- `genplan.jpg` — рендер генплану від клієнта (2000×1123; у кадрі збільшено ~1,7×); у ролику й на обкладинці — розмита
  копія `genplan-soft.jpg` (`npm run zerna:soft`): на фазі 0 видно силуети будинків, а не деталі;
  поверх світла тихий рядок «Деталі згодом…» (`src/zerna/Hint.tsx`);
- `music.wav` — доріжка з референсу без змін; `music-tail.wav` — до 12,45 с ідентична, далі відлуння останнього
  удару в темпі 150 BPM, затихає до 14,9 с (`scripts/zerna-tail.py --src public/zerna2/music.wav … --bpm 150`).

Шрифти, кольори й логотип спільні з першим тизером (`public/zerna/`).

## Збірка і перевірка

```bash
npm run zerna2:assets   # стіна, папір, іконка, відлуння
npm run zerna2:render   # renders/zerna-teaser-2.mp4
npm run zerna2:check    # QA проти референсу
```

`scripts/zerna2-check.mjs`: 1080×1920, 30 fps, 450 кадрів, H.264 yuv420p, BT.709; постери наклеюються на тих самих
кадрах, що в референсі; тон фону стробоскопа збігається в усіх 107 кадрах; музика стартує синхронно; після кінця
вихідного файлу звучить відлуння, у точці повтору тиша; гучність −16…−12 LUFS, пік ≤ −0,5 dBFS.
